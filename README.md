# mihu CLI

Command-line interface for [mihu](https://mihu.ai). This repository only hosts the release
binaries; the installer downloads from here.

## Install

macOS / Linux:

    curl -sSL https://mihu.ai/install.sh | bash

Windows (PowerShell):

    irm https://mihu.ai/install.ps1 | iex

Or download the archive for your platform from the latest release and put `mihu` on your PATH.
Every archive is listed in `checksums.txt` (SHA-256).

## Get started

    mihu login
    mihu agents list
    mihu --help

Documentation: https://developers.mindhunters.ai
